brailleline simulator

A 40-cell refreshable braille line, drawn at real size (dots 2.5 mm apart, cells 6.0 mm apart). Type something and watch which dots have to move, and how many the power budget lets move at once.

Model only: each dot is a bistable pin that takes one 120 mA, 3 ms coil pulse to flip and draws nothing while it holds. No hardware was built. Same scheduler as the C firmware core (source). Plain letters and digits only, no contractions.
